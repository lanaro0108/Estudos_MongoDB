# Estudos_MongoDB

Repositório criado para armazenar meus estudos, exercícios e práticas com **MongoDB**, explorando conceitos de bancos de dados NoSQL e o uso do MongoDB Compass e MongoShell.

## Conteúdos

- Criação e gerenciamento de bancos de dados
- Collections e documentos
- Operações CRUD
- Consultas e filtros
- Atualização e exclusão de dados
- Uso do MongoDB Compass
- Comandos do MongoShell

## Objetivo

Praticar MongoDB por meio de exercícios e pequenos projetos, desenvolvendo conhecimentos em bancos de dados NoSQL e sua aplicação no desenvolvimento de sistemas.

## Tecnologias

- MongoDB
- MongoDB Compass
- MongoShell
